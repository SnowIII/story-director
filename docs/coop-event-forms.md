# Coop 事件形式素材库

Rank 蓝图决定本阶推进什么成长；事件形式决定双方具体做什么。内置素材库提供六类、36 种形式。设计时结合人物、当前现场及全部历阶摘要选择一种主形式，最多搭配一种辅助形式，也可衍生符合设定的新形式，不按列表机械轮换。

| 类型 | 可用形式 | 互动重点 |
|---|---|---|
| 生活合作 | 合伙经营、同做一餐、手艺修缮、分工打理、互换职责、教学互换 | 习惯、偏好、分工与彼此的专长 |
| 探索调查 | 双人踏勘、物件溯源、多方证词、假设实验、现场重构、协同脱困 | 观察、判断、求证与配合 |
| 共同创造 | 联合作品、活动筹备、资源合用、友好竞赛、履行旧约、长期工程的一步 | 实际成果、贡献与可履行的承诺 |
| 社交责任 | 社交引荐、共同接待、局部谈判、第三方调停、功劳与名誉分配、公共事务 | 对外相处、责任范围与合理立场 |
| 信任边界 | 坦诚分歧、双向托付、角色照顾玩家、道歉与补偿、合理拒绝、旧约的新检验 | 双向支持、意愿与边界的实际落实 |
| 轻松纪念 | 节庆游玩、低风险乌龙、共同寻乐、私人纪念、庆祝小胜利、未来安排的试行 | 趣味、欣赏、共同经历与舒服的相处方式 |

每种形式都包含可参与的事项、真实回应机会和局部落点。角色可以主动帮助、教导、照顾或组织合作；玩家也能提出另一种办法。温和的互动不必添加危机或强迫二选一，字段 `conflict` 可以写需要协调、探索的事项，或说明没有外部冲突。

例如，同一位手艺伙伴可以先一起修复旧物，在后来的教学互换中展示另一种专长，再为已有合作成果商量署名，最终实际试行长期工作安排。它们推进不同的行动与关系问题，不需要每阶重复“透露伤痛—请求安慰—重新获得信任”。选用哪种形式仍取决于人物设定、阶段目标和实际剧情。

素材库不等于世界事实。不会为适配形式要求模型另造敌人、能力或身世秘密；道歉只承接已经发生的过错，庆祝只承接已有成果，脱困只承接已有危机。长期工程需要完成本次可验收的一步，不能只订计划就归档。关系确认仍等待真实回应与面板选择。

## 自定义

在世界书「故事导演」中编辑 **`[coop_forms] Coop 事件设计 · 事件形式素材库`**，保留条目名里的标签。

- 条目开启且内容非空时，使用整条自定义内容替代内置素材库；关闭、缺失或留空时回退内置默认值。
- 与 `[coop_design]` 通用规则及 `[coop_rank_4/7/10]` 流程分别判断开关。可以只改形式，也可以只改阶段目标。
- 可以删减类型、调整风格、增加世界观专属形式；写清具体行动、玩家能回应的内容与实际收束条件，避免只列场景名。
- 自动升级保留自定义文本和开关；修改在下一次设计或「重设未演部分」时读取。

素材库只随原有的事件设计请求发送一次，不增加 API 调用，不随每轮正文或 MVU 数值规则重复注入。实际演出仍只注入当前事件与当前阶段需要的提示。已有事件和归档不会被追溯改写。
