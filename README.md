## 一、安装与前置

### 必需的东西

| 依赖 | 必需 | 说明 |
|---|---|---|
| [SillyTavern](https://github.com/SillyTavern/SillyTavern) | ✅ | 实测 1.19.x |
| [酒馆助手 JS-Slash-Runner](https://github.com/N0VI028/JS-Slash-Runner) | ✅ | 提供 `Mvu` 与事件总线 |
| [MagVarUpdate（MVU）](https://github.com/MagicalAstrogy/MagVarUpdate) | ✅ | 变量系统本体 |
| [故事神谕 Story Oracle](https://github.com/namelessone88/story-oracle) | ✅ | 借它的模型连接生成剧情；没有它就只能手写拍列表 |
| [ST-Prompt-Template](https://github.com/zonde306/ST-Prompt-Template) | 可选 | 世界书里的变量快照靠它渲染；不装不影响主体 |

**角色卡必须带有 MVU 变量脚本**，否则插件没法初始化自己的命名空间，装了也不会动。

### 安装

**方式 A：酒馆内一键安装（推荐）**

1. 打开 SillyTavern → **扩展（Extensions）** → **Install extension**
2. URL 填：

   ```
   https://github.com/SnowIII/story-director
   ```

3. 分支留空（默认 `main`）
4. 看到 `Extension '故事导演（自动推进剧情）' has been installed successfully!` 后，**刷新页面（F5）**，
   在扩展列表里启用「**故事导演**」

**方式 B：手动拷目录**

把 `story-director` 整个目录放进：

```
SillyTavern/public/scripts/extensions/third-party/
```

然后刷新页面。**别漏掉 `worldbook/` 子目录** —— 剧本规则与变量契约都在里面。

### 怎么确认装好了

- 屏幕左下出现一个圆形的**场记板**图标（可拖动）→ 点它打开面板
- 面板「设定」页有「**故事神谕兼容性**」卡片，会写「✓ 接口齐全」或「可用，但缺：…」

**自带的世界书会自己装好**：插件启动时发现酒馆里没有「故事导演」这本世界书，会自动装一份并挂到全局
（可在「设定」页关掉自动安装 / 挂载）。

### 升级

在酒馆扩展列表里对本扩展点「更新」（`manifest.json` 已开 `auto_update`），更新后**刷新页面**。

**自带世界书也会跟着更新**（可在「设定」页关掉「自动更新自带世界书」）：插件发现酒馆里那本
「故事导演」比自己带的旧，就会先把它**备份**成「故事导演（更新前备份 x.y.z）」，再写入新的一份 ——
所以你自己往里加过的条目不会凭空消失，翻备份就能拿回来。跨大版本时值得看一眼更新记录。

## 二、自动运行方法

**你什么都不用配。** 装好、启用、正常和角色卡聊天就行。

- 聊满 2 轮 → 插件自动定一部**篇章**（这条长线围绕你展开）
- 聊满 3 轮 → 自动开**第一章**，之后按拍推进
- 章目标达成 → 自动开下一章；中间的空档自动用**间章**、**支线**、**插曲**填上

> ⚠ 这两个「几轮」是**从这个聊天被插件接管**那一刻开始数的，不是这个聊天的全部历史。
> 所以**切到一个几百楼的老聊天不会立刻烧一次生成** —— 它会先看你新聊的两轮。

**你要做的只有一件事：正常演。** 想介入时再看第五、六节。

### ⏻ 总开关（面板最上面那一条）

插件是**全局**的：你在哪个聊天，它就在哪个聊天按自己的判断动手。不想让它动，就

> 点面板**最上面**那条 **⏻ 总开关**。开着是绿边，关掉是红边 —— 一眼能看出此刻它会不会花钱。

关掉之后：**不再自己调模型**（不定篇章、不开章、不换拍、不补支线 / 插曲、审查打回也不重排），
**注入与手动按钮照常** —— 你想生成什么就自己点（那些按钮都在，点了就干活）。

> 从关拨到开时会**重新计时**：不会因为你正好在一个几百楼的老聊天里，一开就立刻烧一次生成。
> 「设定」页里那个「总开关」勾和它是**同一个开关**，改哪边都一样。

> ⚠ 每次自动生成都是**一次真实的模型调用**，用的是「故事神谕」里填写的那个模型。
> 嫌损耗快就去看第四节把节奏调慢，或直接关掉总开关。

## 三、故事基调选择

基调决定这条长线**是什么型的故事**，**由你选，不由模型判断**。

位置：面板「**篇章**」页 → 「篇章（围绕 {{user}} 的长线）」卡片 → **基调**下拉。

三种可选：

| 基调 | 什么时候用 |
|---|---|
| **自动（按角色卡与当前剧情自己判断）** | 默认。懒得选就用它 |
| **奇幻 / 异世界 · 冒险史诗** | 剑与魔法、旅途与阴谋那种 |
| **都市 / 日常 · 生活中的暗流** | 现代都市、日常向。**「日常」不等于没有冲突** —— 暗流与矛盾照样有 |

**建议定篇章之前就选好**：定完篇章再改基调，得点「重新定篇章（换一部）」才生效。

## 四、节奏控制

所有节奏都按「**轮**」记账（1 轮 = 1 条 AI 回复），**完全不看墙钟** ——
挂机三天回来不会一口气冒出十条新线。

默认大约**每 24 轮一章主线**，中间用一段间章、一条支线与一条小插曲把空档填上。

### 主要旋钮（面板「设定」页）

| 项 | 默认 | 作用 |
|---|---|---|
| 每多少轮加一条支线 | 10 | 调大＝更少 |
| 每多少轮加一条插曲 | 10 | 调大＝更少 |
| 每章拍数 | 4 | 一章要演几拍（3~6） |
| 换拍最小间隔 | 1 | 一拍至少演几轮才允许换拍 |
| 开间章前再等几轮（余波） | 3 | 一章收尾后先让余波写完 |
| 一段间章最多几个日常画面 | 3 | 间章不必跑完，随时可以回主线 |

### 四道「别一直生成」的闸门

| 项 | 默认 | 作用 |
|---|---|---|
| 任意两次生成的最小间隔 | 3 | **跨线生效**。没有它，支线和插曲会在同一轮一起冒出来 |
| 上一章收尾后隔几轮才开下一章 | 4 | 留出「余波」的时间 |
| 新章开头几轮先不插支线／插曲 | 3 | 让主线先立住 |
| 开间章前再等几轮（余波） | 3 | 同上，管间章 |

- **觉得太快**：把「生成最小间隔」调到 6~10、「每多少轮加支线／插曲」调到 20+
- **觉得太慢**：把上面几个调小；但记得每次自动生成都是一次真实调用

面板「当前」页的导演状态卡片里有一行**实时节奏提示**，随时告诉你「下一次什么能生成、还要等几轮」，不用猜。

## 五、各个按钮作用

左下角圆形**场记板**图标（可拖动）→ 打开面板。五个页签 + 一个设定页。

### 当前

正在演的章与拍列表（`✔` 已演、`▶` 本轮、`·` 未到）、支线、插曲、导演状态。
间章时段这一块会整块换成间章内容（主线变灰收着）。

### 篇章

查看 / 手改这条长线（篇章、大阶段、伏笔、既成事实、进程），以及**基调下拉**。

**篇章是「大势」不是章纲** —— 它只讲整部戏分几个大阶段、在争什么。
**一章内部怎么起承转合，由主线自己设计**，所以不用在这里安排章节。

- **现在定一部篇章** —— 手动定篇章（一般自动就定了），会开一个窗口让你填要求
- **按现在的情况重新校准** —— 你偏离了原计划，让它跟上来
- **重新定篇章（换一部）** —— 整条线推倒重来
- **保存篇章** —— 手改之后保存

> 上面三个生成按钮都会**先弹一个窗口**：你可以写下对这条篇章的要求与倾向
> （例如「想要一条关于旧账的线，别搞世界危机」「结局别是简单的胜利」），
> 顺手还能改基调。**留空就让它自己按角色卡与当前剧情判断**。
> 自动定篇章（聊满 2 轮自动定篇章、每开新章前自动校准）不会弹窗。
>
> 💡 **弹窗里有「记住它，每轮都带上」** —— 想让这个要求**一直生效**（包括审查打回重写、
> 自动换章时）就点它。钉住之后弹窗开会回填给你看（带 📌），想改就改、想撤就点「清掉钉住的要求」。
> **章节要求**换章后自动失效；**篇章要求**跟这一部篇章走。
>
> ✍️ **还能批一句「朱批」**（就是那一栏「上一版哪里不行」）：
> 「跟上一版几乎一样，只换了说法」「太像世界危机了，我要的是人情账」。
> 只说「我要什么」它容易把上一版照抄一遍、把新要求贴旁边；点出**哪里不行**它才知道要动哪里。
> ⚠ 朱批**只批这一版**（不落盘）：想让某条要求往后一直生效，写在「要求」里按「记住它」。

### 主线

直接编辑章标题、分卷（这一章属于哪一部）、范围、章目标、拍列表。

- **设计下一章** —— 让神谕按当前处境写一章（含拍列表）
- **重新生成本章** —— 整章推倒重写（正文模型报「这一拍站不住」时最有用）
- **只重排剩下的拍** —— 保留已演过的拍，只重写第 N 拍之后
- **保存这一章**

> **关于「进度会不会被打回去」** ——
> **只有「重新生成本章」**会把拍号退回第 1 拍（你明确说要推倒重写）。
> 其它所有情况（审查打回重排、「采用为本故事的下一章」、自动开章）
> 都会**保住已经演过的拍**，新设计的拍接在**后面** ——
> 演到第 2 拍时重生成，你还是从第 2 拍继续，不会重头再来。

> 上面两个**生成按钮都会先弹一个窗口**：你可以写下**对这一章**的要求与倾向
> （例如「这一章我想让她先发现自己被跟踪，别直接摊牌」「少写打斗，多写试探」），
> 顺手还能调**这一章几拍**（3~6）。**留空就让它自己按当前处境判断**。
> ⚠ 这是给「这一章」的方向，不是给整部戏的 —— 整部戏的大势由**篇章**管。
>
> 💡 **弹窗里有「记住它，每轮都带上」** —— 点它之后，**审查把这一章打回重写时也不会丢掉你的要求**
> （重排剩下的拍、自动换章都会带上）。换章后自动失效。
>
> ✍️ **还能批一句「朱批」**（那一栏「上一版哪里不行」）：
> 「第 2 拍就摊牌了，太快，我要慢慢试」「全是打斗，我要的是人情和试探」。
> ⚠ 朱批**只批这一版**（不落盘）：想让某条要求往后一直生效，写在「要求」里按「记住它」。

### 演不下去的时候：合理性审查（自动的，你不用管）

正文模型写正文时如果发现**这一拍和当下的处境对不上**，它会自己报一个信号。插件只做两件事：

| 第几次报 | 插件做什么 |
|---|---|
| **第 1、2 次** | **重排还没演的拍**（已经演过的一字不动）。第 2 次起措辞加硬：换一套推进方式 |
| **第 3 次**（同一章累计） | 判断为**这一部往后几章的方向立不住** → 只**改掉还没写的章**，再重排这一章剩下的拍 |

> 只有**第 3 次**才会碰到篇章，而且**同一章最多动一次** —— 不会「改完又报、报了又改」。
> 三次以内都**不会**把已经演过的拍丢掉（那是「重新生成本章」才会做的事）。

- **计数按章累计**，不要求连续（中间有一次审查通过也不算白攒）。
- **换章就归零**（新的一章重新算三次）；你自己点「重新生成本章」整章重写也算新的一章。
- **不会太频繁**：两次自动重排之间至少隔几轮（默认 3，可在「设定」页调）。
- 屏幕上会显示它做到第几次，「当前」页的导演状态也会写「这一章第 x/3 次被报不合适」。
- 想完全关掉自动重排：设定页关掉「拍站不住时重新设计」，或直接关面板顶上的 ⏻ 总开关。

> 另外，**生成章节时**神谕就会先做一次自检（拿每一拍对当前的时间 / 地点 / 在场的人 / 关系状态过一遍，
> 走不通的当场换掉），**篇章每次校准前也会自检**（「下一章还能不能从当前处境自然长出来」）。
> 所以大部分不合理在**落笔之前**就被拦掉了，轮不到正文模型去硬演。

### 间章

编辑标题 / 场合 / 日常画面列表。

- **现在开一段间章** —— 不等余波，立刻进间章
- **换一段间章** —— 重写这一段
- **手动推进一个画面**
- **现在回主线** —— 收掉间章，接回主线
- **保存这段间章**

### 支线 / 插曲

逐条查看、标记完成、删除。

- **加一条支线** / **加一条插曲** —— 手动新增
- **管理支线** / **管理插曲** / **标记已演** / **标记完成** / **删除** / **让神谕再加一条**

### 设定

分四块：

**自动化开关**（默认全开）

| 开关 | 作用 |
|---|---|
| 总开关 | 关掉＝只手动生成与采用（与面板顶上那个 ⏻ 是同一个） |
| 自动换拍 | 当前拍落了就进入下一拍 |
| 自动换章 | 章目标达成后开下一章 |
| 自动续支线 | 按上面节奏自动加 |
| 自动加插曲 | 不占幕的随机小段 |
| 拍站不住时重新设计 | 正文模型报「调整 / 驳回」时重排还没演的拍（同一章第 3 次才改篇章） |

**注入开关**

| 开关 | 作用 |
|---|---|
| 注入主线引导 | 主线那一拍的引导 |
| 注入支线 / 注入插曲 | 同上，各自的 |
| 注入变量契约 | 告诉正文模型怎么回报进度。**别关**，关了拍就不会自动推进 |
| 强制「不安排 {{user}} 的行为」 | **默认开着，别关** —— 关了就允许导演替你安排行为 |
| 注入深度 | 越小离最新一条越近（默认 4） |
| 同时在演的支线 / 插曲上限 | 默认 2 / 1 |

**生成用上下文**

- **生成时把最近对话捎给故事神谕**（默认开）
- **给神谕的世界书**：角色卡 / 对话绑定的（默认）· 所有已挂载的 · 不带
- **世界书档位**：`全部`（默认）· `精简` · `只有变量契约`

**世界书**

- **缺失时自动安装自带世界书**（默认开）
- **安装后挂到全局世界书**（默认开）
- **安装／重装自带世界书** / **刷新列表** / **挂载到全局世界书**

## 六、手动控制

自动导演不用关，也能随时插手。**随时可做的**：

| 想做的事 | 点哪 |
|---|---|
| 换一章的走向 | 「主线」页 → **重新生成本章** 或 **只重排剩下的拍** |
| 立刻进 / 出间章 | 「间章」页 → **现在开一段间章** / **现在回主线** |
| 拍卡住了 | 「当前」页 → **手动推进一拍** |
| 这一章演够了 | 「当前」页 → **本章收尾**（然后自动换章） |
| 加一条线 | **加一条支线** / **加一条插曲** |
| 全部停下来 | 面板**最上面**的 **⏻ 总开关**（「设定」页那个勾是同一个） |
| 重来 | **清空这个故事** |

### 常见问题

**装了但什么都不发生？**
依次查：MVU 有没有加载（面板「导演状态」会写）→ 世界书「故事导演」有没有挂上 →
故事神谕扩展有没有启用 → 这个聊天有没有聊过至少一句。

**拍一直卡在第一拍？**
正文模型没写回报命令。点**手动推进一拍**纠偏；也可以把注入深度调小（离最新一条更近），
或检查「设定」页的**注入变量契约**有没有被关掉。

**它自己聊了几轮就开了一章？**
默认就是自动的（**从插件接管这个聊天**算起满 3 轮、没有拍列表时开第一章）。
不想要就关「自动换章」或面板顶上的 ⏻ 总开关。

**费 token 吗？**
每次生成都是一次真实调用，上下文带世界书 + 近期对话 + 当前变量。嫌贵就调慢节奏，或关掉总开关。
另外：**切到别的聊天不会立刻生成**（那是 0.24.0 修掉的）—— 插件要先在新聊天里看你聊两轮。

**「篇章 / 主线」到底存在哪？换卡或清变量会丢吗？**
- **剧情计划住在插件里**（每聊天一份，跨刷新不丢）：篇章、章表、大高潮、这一章的拍、支线、插曲、章节史。
- **MVU 变量里只有几个「回报开关」**：`主线.当前拍 / 本拍已落 / 章目标达成 / 可进下一章 / 已收尾 /
  合理性审查 / 审查说明`、`间章.本拍已落 / 已演够 / 可回主线 / 进行中`，以及支线·插曲的「已落」。
  它们存在的唯一理由是**正文模型要自己写** —— `_.set('故事导演.主线.本拍已落', true)` 就是「AI 自己推进」的通道。
- 所以：**换卡 / 重装 / 变量被清空，最多丢一次「这一拍落了没」的信号，不可能弄丢一部篇章**，
  也不会因此重新花一次神谕。
- 正文模型从**注入块**里看该演什么（注入是插件每轮渲染的），所以计划不在变量里它也照样照计划演。
- 老存档（计划原来整棵住在变量里）会在第一次打开时**自动搬进插件**，变量里那份旧计划顺手清掉（只留开关）。
- 想彻底重来：「当前」页 → **清空这个故事**。

**会污染我的聊天记录吗？**
正文模型偶尔会把注入块的标签抄进回复，插件会在回复落地后确定性剥离它（只动它自己那一个）。
变量命令由插件自己接管落盘，不会写进正文。
