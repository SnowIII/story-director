## 一、安装与前置

### 必需的东西

| 依赖 | 必需 | 说明 |
|---|---|---|
| [SillyTavern](https://github.com/SillyTavern/SillyTavern) | ✅ | 实测 1.19.x |
| [酒馆助手 JS-Slash-Runner](https://github.com/N0VI028/JS-Slash-Runner) | ✅ | 提供 `Mvu` 与事件总线 |
| [MagVarUpdate（MVU）](https://github.com/MagicalAstrogy/MagVarUpdate) | ✅ | 变量系统本体 |
| [故事神谕 Story Oracle](https://github.com/namelessone88/story-oracle) | ✅ | 借它的模型连接生成剧情；没有它就只能手写拍列表 |
| [ST-Prompt-Template](https://github.com/zonde306/ST-Prompt-Template) | 可选 | 世界书里的变量快照靠它渲染；不装不影响主体 |

**角色卡必须带有 MVU 变量脚本**，否则插件没法初始化自己的命名空间，装了也不会动。

### 安装

**方式 A：酒馆内一键安装（推荐）**

1. 打开 SillyTavern → **扩展（Extensions）** → **Install extension**
2. URL 填：

   ```
   https://github.com/SnowIII/story-director
   ```

3. 分支留空（默认 `main`）
4. 看到 `Extension '故事导演（自动推进剧情）' has been installed successfully!` 后，**刷新页面（F5）**，
   在扩展列表里启用「**故事导演**」

**方式 B：手动拷目录**

把 `story-director` 整个目录放进：

```
SillyTavern/public/scripts/extensions/third-party/
```

然后刷新页面。**别漏掉 `worldbook/` 子目录** —— 剧本规则与变量契约都在里面。

### 怎么确认装好了

- 屏幕左下出现一个圆形的**场记板**图标（可拖动）→ 点它打开面板
- 面板「设定」页有「**故事神谕兼容性**」卡片，会写「✓ 接口齐全」或「可用，但缺：…」

**自带的世界书会自己装好**：插件启动时发现酒馆里没有「故事导演」这本世界书，会自动装一份并挂到全局
（可在「设定」页关掉自动安装 / 挂载）。

### 升级

在酒馆扩展列表里对本扩展点「更新」（`manifest.json` 已开 `auto_update`），更新后**刷新页面**。

**自带世界书也会跟着更新**（可在「设定」页关掉「自动更新自带世界书」）：插件发现酒馆里那本
「故事导演」比自己带的旧，就会先把它**备份**成「故事导演（更新前备份 x.y.z）」，再写入新的一份 ——
所以你自己往里加过的条目不会凭空消失，翻备份就能拿回来。跨大版本时值得看一眼更新记录。

## 二、自动运行方法

**你什么都不用配。** 装好、启用、正常和角色卡聊天就行。

- 聊满 2 轮 → 插件自动定一部**篇章**（这条长线围绕你展开）
- 聊满 3 轮 → 自动开**第一章**，之后按拍推进
- 章目标达成 → 自动开下一章；中间的空档自动用**间章**、**支线**、**插曲**填上

> ⚠ 这两个「几轮」是**从这个聊天被插件接管**那一刻开始数的，不是这个聊天的全部历史。
> 所以**切到一个几百楼的老聊天不会立刻烧一次生成** —— 它会先看你新聊的两轮。

**你要做的只有一件事：正常演。** 想介入时再看第五、六节。

### ⏻ 总开关（面板最上面那一条）

插件是**全局**的：你在哪个聊天，它就在哪个聊天按自己的判断动手。不想让它动，就

> 点面板**最上面**那条 **⏻ 总开关**。开着是绿边，关掉是红边 —— 一眼能看出此刻它会不会花钱。

关掉之后：**不再自己调模型**（不定篇章、不开章、不换拍、不补支线 / 插曲、审查打回也不重排），
**注入与手动按钮照常** —— 你想生成什么就自己点（那些按钮都在，点了就干活）。

> 从关拨到开时会**重新计时**：不会因为你正好在一个几百楼的老聊天里，一开就立刻烧一次生成。
> 「设定」页里那个「总开关」勾和它是**同一个开关**，改哪边都一样。

> **关掉时会顺手把自带世界书从全局挂载摘掉，开回来时挂回去。**
> 因为世界书是**酒馆**在注入的、不归插件管：插件停了，那本契约还会每轮塞「你会收到幕后演出计划」，
> 模型于是在等一份不会来的计划 —— 关掉之后聊天反而更别扭。
> **只摘我们挂的那一次**：你本来没挂、或你自己摘的，开回来都不会擅自挂上。
> 不想让它动酒馆的世界书，就去「设定」页关掉「关总开关时顺手摘掉全局挂载」。

> ⚠ 每次自动生成都是**一次真实的模型调用**，用的是「故事神谕」里填写的那个模型。
> 嫌损耗快就去看第四节把节奏调慢，或直接关掉总开关。

### ⏳ 正在生成…（总开关下面那一条）

只要有模型调用在跑，总开关下面就会冒出一条**琥珀色**的提示，切到哪个页签都看得见：

> **◌ 正在生成「下一章」… 12s · 已收 340 字**　　`[中断]`

- **转圈**表示它在跑；**名字**告诉你它在生成什么（篇章 / 篇章检查 / 下一章 / 重写这一章 / 间章 / 支线 / 插曲）；
  **秒数**每秒钟自己走；**字数**在流式输出时会往上涨。
- **点「中断」= 真的掐断这次请求**（不是等它跑完再丢掉）—— 请求会立刻中止，不再继续烧 token。
  中断之后**没有失败记录**，也不会白等退避，你可以马上重新生成。
- 中断只影响**这一次**调用：已经落盘的剧情、注入状态都不动。
- 排查用：控制台里 `__storyDirector.generating()` 看现在在生成什么，`__storyDirector.abort()` 手动掐一次。

## 三、故事基调选择

基调决定这条长线**是什么型的故事**，**由你选，不由模型判断**。

位置：面板「**篇章**」页 → 「篇章（围绕 {{user}} 的长线）」卡片 → **基调**下拉。

三种可选：

| 基调 | 什么时候用 |
|---|---|
| **自动（按角色卡与当前剧情自己判断）** | 默认。懒得选就用它 |
| **奇幻 / 异世界 · 冒险史诗** | 剑与魔法、旅途与阴谋那种 |
| **都市 / 日常 · 生活中的暗流** | 现代都市、日常向。**「日常」不等于没有冲突** —— 暗流与矛盾照样有 |

**建议定篇章之前就选好**：定完篇章再改基调，得点「重新定篇章（换一部）」才生效。

## 四、节奏控制

所有节奏都按「**轮**」记账（1 轮 = 1 条 AI 回复），**完全不看墙钟** ——
挂机三天回来不会一口气冒出十条新线。

默认大约**每 12~15 轮一章主线**（4 拍 × 一拍至少 3 轮），中间用一段间章、一条支线与一条小插曲把空档填上。

### 主要旋钮（面板「设定」页）

| 项 | 默认 | 作用 |
|---|---|---|
| 每多少轮加一条支线 | 10 | 调大＝更少 |
| 每多少轮加一条插曲 | 10 | 调大＝更少 |
| 每章拍数 | 6 | 一章要演几拍（3~8）。一拍 = 一个来回，所以一拍通常就是一条回复 |
| 换拍最小间隔 | **1** | 一拍演完就进下一拍（1 = 不硬等）。想让它慢下来就调大 —— 但那是**空等**，一般不必 |
| 开间章前再等几轮（余波） | 3 | 一章收尾后先让余波写完 |
| 一段间章最多几个日常画面 | 3 | 间章不必跑完，随时可以回主线（画面都发生在主角团身边） |
| 废弃篇章的防重复记录留几轮 | 5 | 被换掉/重新生成的篇章不进归档，只留这么多轮提醒，之后自动清掉 |

> **一章大概几条回复**：≈ 拍数（一拍一条，因为一拍就是一个来回）。
> 所以节奏的旋钮是**拍数**，不是「等几轮」—— 后者是空转。

> **「推得太快 / 太慢」怎么调**：节奏的旋钮是**每章拍数**（一拍 ≈ 一条回复）。
> 觉得一章过得太快就把拍数调大（一拍到 6~8），觉得一章拖太久就调小 ——
> 不要再靠「换拍最小间隔」去拖：那是**空等**，那几轮拍已经演完了，只会让模型重复。
>
> 内容上的两条纪律由注入保证：**换场必须先演过渡**（不许一句话从宿舍切到列车），
> 并且**拍号由插件推进** —— 模型自己改 `当前拍` 不算数，节奏不会被偷偷踩油门。

### 四道「别一直生成」的闸门

| 项 | 默认 | 作用 |
|---|---|---|
| 任意两次生成的最小间隔 | 3 | **跨线生效**。没有它，支线和插曲会在同一轮一起冒出来 |
| 上一章收尾后隔几轮才开下一章 | 4 | 留出「余波」的时间 |
| 新章开头几轮先不插支线／插曲 | 3 | 让主线先立住 |
| 开间章前再等几轮（余波） | 3 | 同上，管间章 |

- **觉得太快**：把「生成最小间隔」调到 6~10、「每多少轮加支线／插曲」调到 20+
- **觉得太慢**：把上面几个调小；但记得每次自动生成都是一次真实调用

面板「当前」页的导演状态卡片里有一行**实时节奏提示**，随时告诉你「下一次什么能生成、还要等几轮」，不用猜。

## 五、各个按钮作用

左下角圆形**场记板**图标（可拖动）→ 打开面板。六个页签：当前 · 篇章 · 主线 · 支线/插曲 · 设定 · 关于。
（页签单独一行且能横向滚动，窄窗口里也不会把标题挤走。）

### 当前

正在演的章与拍列表（`✔` 已演、`▶` 本轮、`·` 未到）、支线、插曲、导演状态。
间章时段这一块会整块换成间章内容（主线变灰收着）。

> **面板上你能看到整章的每一拍，但注入给正文模型的只有 `▶` 那一条。**
> 这是刻意的：让叙事者一眼看完后面的走向，它就会急着往前赶、把还没铺的伏笔提前兑现
> （「编排泄漏」）。后面几拍的**内容**只有你（和神谕）看得到，模型只在轮到它时才知道。
> 间章同理：注入每轮只给**当前那一个画面**。

### 篇章

查看 / 手改这条长线（篇章、章表、伏笔、既成事实、大高潮），以及**基调下拉**。

页尾有一个折叠块「**已完结的篇章（归档）**」：

> 一部**演义完了**（章表写满）就会自动归档 —— 它**不再参与提示词注入**，
> 只在这里留档：章表、大高潮、既成事实、伏笔、写了多少章、什么时候结束的。
> 归档同时让**新的那部**知道要避开什么（不然新一部就是旧一部的换皮）。
> 章表与大高潮折在「会剧透」里。
>
> **只归档正常演义完的。** 被换掉 / 重新生成的那些（废弃篇章）**不进归档** ——
> 它们只作为「下一次别写成一样」的提醒留在防重复名单里，过若干轮（默认 5，
> 见「设定」页）就自动清掉。
>
> **一部演完之后会自动开下一部**：最后一章收尾（走间章的话就是间章演完之后）
> 就会请神谕定新的一部，然后从它的第 1 章开始。

**篇章是「大势」不是章纲** —— 它讲整部戏在争什么，然后**一次排满整部**：一条一章，
每条里都写全一套 `起 / 承 / 转 / 合`（为什么进这一章 / 在争什么 / 最要紧那一下 / 落定成什么样）。
**每章自己是一套起承转合，四条合起来又是一套更大的**（1 起、2 承、3 转〔大高潮〕、4 合）。

**四章不是「一件事的四个阶段」**：章表**每一条以〔舞台〕开头**，四章的舞台**必须四处不同**；
每章各办一件事（别的地区 / 别的人 / 别的麻烦），章与章靠**暗线**连 ——
一条反复出现的信物、一个只在幕后出手的势力、某人的处境一章挪一格、一句从不同人口中听来的话。
判据：**把中间两章对调，故事还成立吗？**

**主角只有 {{user}}**：每一章都要有冲着他来的那一层 —— 不许把整部演成某个 NPC 的个人史
（那个 NPC 戏再多也是配角），也不许替他行动（写「世界怎么压过来」，不写「他决定 / 他试图 / 他带领」）。

**这一章具体怎么演（每一拍是什么、从哪里切入）由主线把它细化成拍**，这里不排；

- **现在定一部篇章** —— 手动定篇章（一般自动就定了），会开一个窗口让你填要求
- **按现在的情况重新校准** —— 你偏离了原计划，让它跟上来
- **重新定篇章（换一部）** —— 整条线推倒重来（当场叫一次神谕）
- **清空篇章与主线** —— 把这一部与**当前这一章**整个删掉，**不叫模型**，等它**自然重新生成**
  （聊满 2 轮自动定新的一部 → 再开第一章）。不动聊天记录、章节史、你钉住的要求与支线。
- **保存篇章** —— 手改之后保存

> 上面三个生成按钮都会**先弹一个窗口**：你可以写下对这条篇章的要求与倾向
> （例如「想要一条关于旧账的线，别搞世界危机」「结局别是简单的胜利」），
> 顺手还能改基调。**留空就让它自己按角色卡与当前剧情判断**。
> 自动定篇章（聊满 2 轮自动定篇章、每开新章前自动校准）不会弹窗。
>
> 💡 **弹窗里有「记住它，每轮都带上」** —— 想让这个要求**一直生效**（包括审查打回重写、
> 自动换章时）就点它。钉住之后弹窗开会回填给你看（带 📌），想改就改、想撤就点「清掉钉住的要求」。
> **章节要求**换章后自动失效；**篇章要求**跟这一部篇章走。
>
> ✍️ **还能批一句「朱批」**（就是那一栏「上一版哪里不行」）：
> 「跟上一版几乎一样，只换了说法」「太像世界危机了，我要的是人情账」。
> 只说「我要什么」它容易把上一版照抄一遍、把新要求贴旁边；点出**哪里不行**它才知道要动哪里。
> ⚠ 朱批**只批这一版**（不落盘）：想让某条要求往后一直生效，写在「要求」里按「记住它」。

### 主线

顶上是一个**当前拍**的数字框（`第 N / 共 M 拍`），下面是编辑区。

直接编辑章标题、分卷（这一章属于哪一部）、范围、章目标、拍列表。

- **设计下一章** —— 让神谕按当前处境写一章（含拍列表）
- **重新生成本章** —— 整章推倒重写（正文模型报「这一拍站不住」时最有用）
- **只重排剩下的拍** —— 保留已演过的拍，只重写第 N 拍之后
- **保存这一章**

> **进间章时，这一页整块变成间章界面** —— 页签里没有单独的「间章」：
> 同一时间只有一种幕在演，所以只有一个地方要看。间章演完回主线，这一页再变回主线。

#### 间章（就在上面这一页里）

编辑标题 / 场合 / 日常画面列表。

- **换一段间章** —— 重写这一段
- **手动推进一个画面**
- **现在回主线** —— 收掉间章，接回主线
- **保存这段间章**

> **一次只演一个画面。** 注入里**只给当前那一个**（后面的画面不会给模型看到，免得它自己往后跳），
> 演完由插件把画面号推进一格 —— 顶上那个 `当前画面 N / M` 会跟着走。
> 你想手动推一格就点「手动推进一个画面」。
>
> **间章是两条主线之间的一条缝**，负责**润滑与填空**：让上一章的余波落地，再平移到下一章的开场。
> 所以它有三条硬规矩：
> **① 人就在身边** —— 写刚收尾那一章里的这批人（他身边的角色、他待的地方、他所属的队伍 / 家 / 铺子）；
> **② 不许另开一条世界线** —— 不跳到与主角团无关的远方城市、不写陌生人视角（远方的教授、边境的军需官那种是设定集，不是间章）；
> **③ 必须带一点与主线有关的信息** —— 上一章的余波、一个与主线有关的决定 / 消息 / 察觉，或下一章会用到的一根线。
>
> 它**不推进主线**（不升级冲突、不给关键转折、不让新角色登场），也**不要求跑完** ——
> 随时可以收尾回主线。
>
> **每一段新间章、每一章新主线都从第 1 拍重新算**，不会沿用上一幕的拍号。

> **关于「进度会不会被打回去」** ——
> **只有「重新生成本章」**会把拍号退回第 1 拍（你明确说要推倒重写）。
> 其它所有情况（审查打回重排、「采用为本故事的下一章」、自动开章）
> 都会**保住已经演过的拍**，新设计的拍接在**后面** ——
> 演到第 2 拍时重生成，你还是从第 2 拍继续，不会重头再来。

> 上面两个**生成按钮都会先弹一个窗口**：你可以写下**对这一章**的要求与倾向
> （例如「这一章我想让她先发现自己被跟踪，别直接摊牌」「少写打斗，多写试探」），
> 顺手还能调**这一章几拍**（3~6）。**留空就让它自己按当前处境判断**。
> ⚠ 这是给「这一章」的方向，不是给整部戏的 —— 整部戏的大势由**篇章**管。
>
> 💡 **弹窗里有「记住它，每轮都带上」** —— 点它之后，**审查把这一章打回重写时也不会丢掉你的要求**
> （重排剩下的拍、自动换章都会带上）。换章后自动失效。
>
> ✍️ **还能批一句「朱批」**（那一栏「上一版哪里不行」）：
> 「第 2 拍就摊牌了，太快，我要慢慢试」「全是打斗，我要的是人情和试探」。
> ⚠ 朱批**只批这一版**（不落盘）：想让某条要求往后一直生效，写在「要求」里按「记住它」。

### 演不下去的时候：合理性审查（自动的，你不用管）

**这一拍是「计划」，不是「保证」。** 正文模型写正文时如果发现对不上的地方，它按**三档**报：

| 有多严重 | 它写什么 | 插件做什么 |
|---|---|---|
| **根本不是问题** | 什么都不写 | 照常推进 |
| **有点对不上，但它自己能改**（换场合 / 换个人触发 / 补一句来由 / 晚点发生 —— **结果不变**） | `调整` | **不重排、不花一次神谕**：只回它一句「照你调整后的演，但这一拍要达到的结果别丢」 |
| **演得出来，但缺一步因**（谁为什么会这么做 / 局面为什么会突然变成这样） | `缺铺垫` | **把这一拍按住**，下一轮提醒它「先补这一步」；补完照常推进 |
| **真的立不住**（要硬加设定 / 会让人物出戏 / 和已发生的事直接矛盾） | `驳回` | 才走打回：重排还没演的拍；**同一章累计 3 次**才会去改篇章，而且**同一章最多改一次** |

> **前两档是给模型的自由裁量权**：不到「打回重写」的地步就不打回 —— 那是零成本的（不调用神谕）。
> 但它**不能改这一拍的目的**：把「让乔治安退让」改成「乔治安根本没来」就不是微调了。

- **打回计数按章累计**，不要求连续；**换章就归零**（「重新生成本章」也算新的一章）。
- **不会太频繁**：两次打回重排之间至少隔几轮（默认 3，可在「设定」页调）。
- 「当前」页的导演状态会写「这一章第 x/3 次被报不合适」、以及**待补的铺垫**是什么。
- 想完全关掉自动重排：设定页关掉「拍站不住时重新设计」，或直接关面板顶上的 ⏻ 总开关。

### 每章演完后：篇章检查（自动的，一次调用/章）

**一章刚演完、新章还不该立刻衔接** —— 正好趁「间章」那几轮，插件静默做一次**篇章检查**：

> 「往后还没写的那几章，在**已经发生的这些事**之后还成立吗？」

- **它只是检查，不是重生成**：成立就**一字不改**（你会看到「篇章检查：往后几章还成立，没动它」）；
- 只有真的走不通的那几章才改，**已经写过的章与标题一个字都不动**；
- **要改就小改**：换成**同一批人、同一处地方能自然发生的等价安排**（换个人来推动、换个场合、换一种施压方式）——
  **不许引入新的灾变 / 机关 / 更大的事件**；
- **不许掀掉你正奔向的东西**：你明显在往某个方向推（期待某场戏、正在促成某件事）时，后面的章要沿着它走。
  天降灾变、第三方插手、「就在…即将…之际，突然…」这些**一律不许** —— 变局要与那件事**并存、或在它之后**；
  也不许为了让角色脱困而降下一个刚好解围的巧合；
- **「你还没做」不等于「不成立」**：判断只看**已经写进正文的事**。你没做、还没出手只是**还没演**，
  不据此提前作废后面的章（以前最容易在这里误伤）；
- 走间章时它**不占你的等待**（在间章那几轮里做完）；不走间章时在开下一章**之前**做掉；
- 开关：设定页「**每章演完后检查一次篇章**」（默认开）；结论会留在面板「当前」页的诊断里。

> 这正是「我明明没帮忙，她却安然度过」那类问题的解药：**旧章刚完是最该回头的时刻**，而不是等下一章撞上墙。

> 另外，**生成章节时**神谕就会先做一次自检（拿每一拍对当前的时间 / 地点 / 在场的人 / 关系状态过一遍，
> 走不通的当场换掉），**篇章校准与检查之前也都会自检**（「下一章还能不能从当前处境自然长出来」）。
> 所以大部分不合理在**落笔之前**就被拦掉了，轮不到正文模型去硬演。

### 间章

> 已并入**「主线」页**（见上）—— 进间章时那一页整块换成间章界面，页签里不再单列。

### 支线 / 插曲

逐条查看、标记完成、删除。

- **加一条支线** / **加一条插曲** —— 手动新增
- **管理支线** / **管理插曲** / **标记已演** / **标记完成** / **删除** / **让神谕再加一条**

### 设定

分四块：

**自动化开关**（默认全开）

| 开关 | 作用 |
|---|---|
| 总开关 | 关掉＝只手动生成与采用（与面板顶上那个 ⏻ 是同一个） |
| 自动换拍 | 当前拍落了就进入下一拍 |
| 自动换章 | 章目标达成后开下一章 |
| 自动续支线 | 按上面节奏自动加 |
| 自动加插曲 | 不占幕的随机小段 |
| 拍站不住时重新设计 | 正文模型报「调整 / 驳回」时重排还没演的拍（同一章第 3 次才改篇章） |
| 每章演完后检查一次篇章 | 趁间章做一次「往后几章还成立吗」的检查：**只判断、默认不改**；改也只小改，不许加灾变（一次调用/章） |

**注入开关**

| 开关 | 作用 |
|---|---|
| 注入主线引导 | 主线**当前那一拍**的引导（只给这一拍，不给后面的） |
| 注入支线 / 注入插曲 | 同上，各自的 |
| 注入变量契约 | 告诉正文模型怎么回报进度。**别关**，关了拍就不会自动推进 |
| 强制「不安排 {{user}} 的行为」 | **默认开着，别关** —— 关了就允许导演替你安排行为 |
| 注入深度 | 越小离最新一条越近（默认 4） |
| 同时在演的支线 / 插曲上限 | 默认 2 / 1 |

> **发给正文的「怎么回报」和「这一轮演什么」是两层，互不干扰：**
> 「怎么回报」+「当前变量快照」由**自带世界书那三个常驻条目**和一条**变量契约槽**提供，**不分幕**；
> 而「这一轮是主线还是间章、该写哪几个字段」在**幕的引导块**里，主线与间章**互斥**。
> 所以间章时段只会看到 `间章.*` 的命令示例（写 `主线.*` 会被忽略），主线时段反之 ——
> 两边不会互相串味。

**生成用上下文**

- **生成时把最近对话捎给故事神谕**（默认开）
- **给神谕的世界书**：角色卡 / 对话绑定的（默认）· 所有已挂载的 · 不带
- **世界书档位**：`全部`（默认）· `精简` · `只有变量契约`

**世界书**

- **缺失时自动安装自带世界书**（默认开）
- **安装后挂到全局世界书**（默认开）
- **关总开关时顺手摘掉全局挂载**（默认开）—— 关掉总开关就一并摘掉，开回来时挂回去（见第二节）
- **安装／重装自带世界书** / **刷新列表** / **挂载到全局世界书**

作者、头像、Discord 与当前版本号。纯展示页，没有任何开关。

## 六、手动控制

自动导演不用关，也能随时插手。**随时可做的**：

| 想做的事 | 点哪 |
|---|---|
| 换一章的走向 | 「主线」页 → **重新生成本章** 或 **只重排剩下的拍** |
| 立刻进 / 出间章 | 「间章」页 → **现在开一段间章** / **现在回主线** |
| 拍卡住了 | 「当前」页 → **手动推进一拍** |
| 这一章演够了 | 「当前」页 → **本章收尾**（然后自动换章） |
| 加一条线 | **加一条支线** / **加一条插曲** |
| 全部停下来 | 面板**最上面**的 **⏻ 总开关**（「设定」页那个勾是同一个） |
| 重来 | **清空这个故事** |

### 常见问题

**装了但什么都不发生？**
依次查：MVU 有没有加载（面板「导演状态」会写）→ 世界书「故事导演」有没有挂上 →
故事神谕扩展有没有启用 → 这个聊天有没有聊过至少一句。

**拍一直卡在第一拍？**
正文模型没写回报命令。点**手动推进一拍**纠偏；也可以把注入深度调小（离最新一条更近），
或检查「设定」页的**注入变量契约**有没有被关掉。

**一直提示「生成失败」？**
先看提示里是哪一种：

- **「上游报错 —— …」/「返回了空内容」** —— **不是插件的问题**，是你用的模型 / 中转那边出错
  （常见的是 `upstream_capacity_exhausted`：上游容量耗尽）。这类错误插件会自动退避 **5 分钟**再试；
  想立刻恢复就换一个模型 / 中转，或过一会儿再来。
- **「没解析到 `<Story…>` 区块」** —— 模型回了话但格式不对。原始回复在**控制台**里，发给我看看。
- **「读不到故事神谕的模型连接」** —— 故事神谕没启用，或版本太老。

> 排查用的原始记录在 `%APPDATA%\com.tauritavern.client\logs\llm-api-*.response.sse`
> （客户端把每次模型调用都写在那儿）—— 上面那类「HTTP 200 但内容里是 error」的坑，
> 一看就明白。

**它自己聊了几轮就开了一章？**
默认就是自动的（**从插件接管这个聊天**算起满 3 轮、没有拍列表时开第一章）。
不想要就关「自动换章」或面板顶上的 ⏻ 总开关。

**费 token 吗？**
每次生成都是一次真实调用，上下文带世界书 + 近期对话 + 当前变量。嫌贵就调慢节奏，或关掉总开关。
另外：**切到别的聊天不会立刻生成**（那是 0.24.0 修掉的）—— 插件要先在新聊天里看你聊两轮。

**「篇章 / 主线」到底存在哪？换卡或清变量会丢吗？**
- **剧情计划住在插件里**（每聊天一份，跨刷新不丢）：篇章、章表、大高潮、这一章的拍、支线、插曲、章节史。
- **MVU 变量里只有几个「回报开关」**：`主线.当前拍 / 本拍已落 / 章目标达成 / 可进下一章 / 已收尾 /
  合理性审查 / 审查说明`、`间章.本拍已落 / 已演够 / 可回主线 / 进行中`，以及支线·插曲的「已落」。
  它们存在的唯一理由是**正文模型要自己写** —— `_.set('故事导演.主线.本拍已落', true)` 就是「AI 自己推进」的通道。
- 所以：**换卡 / 重装 / 变量被清空，最多丢一次「这一拍落了没」的信号，不可能弄丢一部篇章**，
  也不会因此重新花一次神谕。
- 正文模型从**注入块**里看该演什么（注入是插件每轮渲染的），所以计划不在变量里它也照样照计划演。
- 老存档（计划原来整棵住在变量里）会在第一次打开时**自动搬进插件**，变量里那份旧计划顺手清掉（只留开关）。
- 想彻底重来：「当前」页 → **清空这个故事**。

**会污染我的聊天记录吗？**
正文模型偶尔会把注入块的标签抄进回复，插件会在回复落地后确定性剥离它（只动它自己那一个）。
变量命令由插件自己接管落盘，不会写进正文。
